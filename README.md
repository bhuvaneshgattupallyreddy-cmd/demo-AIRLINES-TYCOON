# ✈️ Airline Tycoon Simulator

## About the Game

Airline Tycoon Simulator is a Python-based airline management game where you become the owner of your own airline.

Start with **$10,000,000**, purchase aircraft, create routes between airports, and operate flights to earn money. Manage your airline's finances, pay flight expenses, and expand your aviation business.

## 🎮 How to Play

1. Enter your name and airline name.
2. Buy aircraft from the aircraft shop.
3. Create flight routes between available airports.
4. Operate flights and transport random numbers of passengers.
5. Earn revenue and pay fuel, crew, and airport expenses.
6. Check your finances and grow your airline!

## ✈️ Features

- Aircraft purchasing system
- Five available airports
- Route creation and management
- Random passenger numbers
- Flight revenue and expenses
- Airline financial management

## 🚀 How to Run

### Requirements
- Python 3
- A terminal or Visual Studio Code

### Steps

1. Download or clone this repository.
2. Open the project folder.
3. Open the terminal in the project folder.
4. Run the game:

```bash
python main.py.py
```

5. Follow the instructions in the game menu.
